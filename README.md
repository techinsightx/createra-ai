> **Transform your raw ideas into professional, ready-to-use content and stunning AI images in seconds.**

Createra AI is a revolutionary, production-ready, full-stack AI platform designed to empower creators, students, and businesses. Built with a focus on speed, security, and multimodal capabilities, it seamlessly converts text, voice, and file inputs into high-quality outputs.

---

## ✨ Key Features

- 🎙️ **Top-Grade Voice Input:** Optimized speech-to-text recognition specifically tuned for Indian accents and Hinglish.
- 📎 **Multimodal File Support:** Upload and analyze Images or PDFs directly within the chat interface.
- 🎨 **Built-in AI Image Generation:** Generate high-quality, 4K resolution images instantly using advanced diffusion models.
- ⚡ **Lightning-Fast Responses:** Powered by the **Groq API** (Llama-3.1-8b-instant) for sub-second text generation.
- 🔒 **Enterprise-Grade Security:** Secure user authentication and session management via **Firebase Auth**.
- 💾 **Persistent Chat History:** Local storage-based chat management that remembers your conversations across sessions.
- 📱 **Fully Responsive UI:** A sleek, glassmorphism-inspired design that works flawlessly on desktop and mobile devices.
